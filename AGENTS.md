# quickstart — agent & contributor contract

A GitHub-template repo for spinning up containerized POCs fast. **Standardize the outside**
(compose, Dockerfile, `.env`, GHCR CI, OTLP, exposure); the language inside is free.

## The stack
- **Postgres** + **Valkey** are always-on core. **pgAdmin** (`tools` profile), **Grafana/otel-lgtm**
  (`observability` profile), and **Traefik + autossh** (`expose` profile) are opt-in.
- `make up` = full local dev (core + tools + observability). `make up-lean` = core only.
- Config is **only** via env (`.env`, generated by `make init`). Apps **log to stdout**.
- The app **owns its schema via its ORM** (migrate on startup). `db/init/` is first-boot bootstrap
  only (extensions/roles) — never migrations.

## Always
- Run `make init` before `make up` (idempotent; generates `.env` + `pgadmin/pgpass`).
- Add config as env vars (12-factor); read them in the app. Log to stdout.
- Keep secrets out of git — `.env`, keys, and `acme.json` are gitignored.
- Pin image major versions in `compose.yaml`.

## Ask (the human) when unsure
- Which language for a new service? (python / node / go recipes exist)
- Does it need to be internet-exposed? (then `make expose` + a bare VPS — see `docs/exposure.md`)
- Should telemetry be on? (`make up` enables it; `make up-lean` doesn't)

## Never
- Commit `.env`, SSH keys, or `acme.json`.
- Add a migration tool (Flyway etc.) — the ORM owns the schema.
- Set `GatewayPorts no` on the VPS, or use `traefik.me` (dead/insecure) — use sslip.io.
- Expose a database without a strong password.

## Add a service
1. `make add-service LANG=python NAME=app`  (copies a runnable recipe into `services/app/`)
2. In `compose.yaml`, uncomment the `app:` block (it matches `recipes/<lang>/service.snippet.yml`);
   if `NAME` ≠ `app`, rename the service + its Traefik router/labels and set `build: ./services/<name>`.
3. Required env (inherited via `env_file: .env`): `POSTGRES_USER/PASSWORD/DB`, `VALKEY_PASSWORD`,
   `OTEL_*`. Optional overrides: `DB_HOST` (default `db`), `VALKEY_HOST` (default `valkey`).
4. `make up` → hit it at `http://127.0.0.1:8000`. To expose publicly: `make expose`.

## Read the right doc for the task (these are NOT auto-loaded — open them on demand)

- GHCR build & publish → `docs/ci.md`

- something broke → `docs/troubleshooting.md`
- going beyond a POC → `docs/production-hardening.md`
- Postgres/Valkey conventions → `docs/database.md`
